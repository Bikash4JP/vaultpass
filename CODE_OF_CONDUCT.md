# Code of Conduct

VaultPass adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as our Code of Conduct.

**Short version:**

- Be respectful. Assume good faith.
- Debate ideas, not people.
- No discrimination, harassment, or exclusion of any kind.
- Violations result in warning → temporary ban → permanent ban.

**Reporting violations:** `conduct@vaultpass.io` *(once configured)* or directly to a maintainer.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
